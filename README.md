# Rv sweets and restaurant

A Django starter website for a sweets shop and restaurant business, with a branded homepage and inquiry form.

## Run locally

```powershell
python -m pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

## Included

- Responsive homepage using HTML, CSS, and JavaScript
- Inquiry form backed by Django and SQLite
- Django admin support for inquiry management
